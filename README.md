# Executive Responder (Claude Plugin)

A modular skill and plugin for Claude designed to draft concise, high-signal, decision-oriented responses for senior leadership, executives, and board members.

## Features

- **BLUF Formatting:** Ensures the critical message is delivered in the first sentence.
- **Decision-Ready Frameworks:** Pre-structured formats for status updates, escalations, sign-offs, and brief answers.
- **Mobile-First Scannability:** Strips corporate filler and organizes information for 30-second reviews.

## Installation

Clone or extract this repository into your local Claude configuration:

```bash
# Claude Code / CLI installation
claude plugin add path/to/executive-responder
```

Or copy the `skills/executive-responder` folder directly into your workspace's `.claude/skills/` directory.

## Usage Examples

Once installed, invoke the skill naturally:

- *"Draft a response to our VP asking why the Q3 migration is delayed by three days."*
- *"Summarize this 10-page post-mortem into a 3-bullet executive briefing for leadership."*
- *"Help me ask the CPO for sign-off on shifting $20k in cloud spend to support load testing."*
